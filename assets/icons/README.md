# Dishari Branding & Icons Directory

This folder contains the official vector assets and branding icons for Dishari (দিশারী):

- **dishari_logo.svg**: Primary cropped light-theme vector logo with Kalpurush Bengali typography (viewBox: 8 8 444 168).
- **dishari_logo_dark.svg**: Primary cropped dark-theme vector logo with Kalpurush Bengali typography (viewBox: 8 8 444 168).
- **dishari_mark.svg**: Standalone square emblem mark (viewBox: 8 8 168 168) suitable for favicons, app icons, touch icons, and mobile splash screens.
